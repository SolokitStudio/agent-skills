## [1.0.0] - 2026-11-02

### Added

- Skills: `solo-product-page-audit`, `solo-pricing-sanity-check`, `solo-say-do-check`, released under the MIT License.
- `install.sh`: one-command install for Claude Code, Cursor, Codex and Gemini CLI, at user or project scope, with `--dry-run`, `--force`, `--link` and `--uninstall`.
- Claude Code plugin and marketplace manifests.
- `scripts/validate.py` and installer tests, run in CI on Linux and macOS.
- A reproducible example for `solo-say-do-check`.
