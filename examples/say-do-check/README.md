# Example: solo-say-do-check

An agent reports four things done. The evidence exports tell a different story.

| File | What it is |
|---|---|
| [`request.md`](request.md) | What the agent was asked to do |
| [`agent-report.md`](agent-report.md) | What the agent said it did |
| [`evidence/`](evidence/) | Mailbox, Stripe and LinkedIn exports |
| [`prompt.md`](prompt.md) | The prompt used |
| [`output.md`](output.md) | The skill's output |

All names, IDs and addresses are fictional. Run it yourself: install the skills, open this folder in your agent, and paste `prompt.md`. Wording will vary between models and runs, but the four results and the safe status line should not.
